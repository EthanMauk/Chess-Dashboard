- test result: PASS

Cancel behavior verified in src/App.jsx
1. Cancel calls AbortController.abort().
2. browserSync throws AbortError after the current Stockfish search boundary.
3. The AbortError handler calls loadPlayerData(), which reloads completed IndexedDB records.
4. If at least one completed record exists, it calls uploadProfileSnapshot().
5. uploadProfileSnapshot() now compares local records with the remote manifest and POSTs only new/stronger records, in batches of <= 1,000.
6. Therefore explicit Cancel does update the GitHub shared cache once for the completed work.
7. A hard browser/tab close still cannot guarantee a remote upload; completed IndexedDB records remain local for the next Sync.
